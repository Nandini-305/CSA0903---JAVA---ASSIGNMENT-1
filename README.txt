JAVA ASSIGNMENT 1 – CAMPUS SMART-PARKING SYSTEM

This folder contains separate runnable Java examples for Tasks 1–12.
Each Task folder contains:
- Main.java: Java source code
- INPUT.txt: sample input (where applicable)
- OUTPUT.txt: expected console output
- README.txt: short description and run command

HOW TO RUN EACH TASK IN VS CODE
1. Extract this ZIP file.
2. Open the required Task folder in VS Code.
3. Open Main.java.
4. Open Terminal > New Terminal.
5. Compile: javac Main.java
6. Run: java Main
7. Enter the values shown in INPUT.txt when prompted.
8. Compare the terminal with OUTPUT.txt and take a screenshot.

IMPORTANT
- Use a separate folder for each task so that each Main.java compiles independently.
